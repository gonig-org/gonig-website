# GONiG Website — Information Needed from the Guild

**Date:** June 2026

---

Please send us the following information so we can complete the website. Each section below tells you exactly what we need.

---

## 1. Zone & Chapter Officers

For each officer across all zones and chapters, please send:

- Full name (with title)
- Their zone or chapter (e.g. Southwest Zone, South-South Zone)
- Their role (e.g. Zonal Chairman, Zonal Secretary)

---

## 2. Member Directory

Please send us a spreadsheet of all registered members with three columns:

- Membership number
- Full name
- Status (Active or Inactive)

---

## 3. Education

We have five education pages that are currently empty. For each one, please send a short description of what the Guild offers in that area.

The five pages are: **Programmes, Mentorship, Training, Certification, Workshops.**

---

## 4. Events

**Forthcoming events** — For each upcoming event, please send the event name, date, venue, and a short description.

**Past events** — If you have photographs from past Guild events (recitals, concerts, inaugurations), please send them along with the event name and year.

**Calendar** — Please send us the dates and names of all scheduled Guild activities for the year so we can populate the events calendar.

---

## 5. Resources

This page will hold documents and materials for members. Please send us any files you would like to make available — for example, the Guild constitution, event programmes, or study materials.
